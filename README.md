Для поиска я взял текст запроса, заголовок, описание и параметры объявления. оставил категорию 114, потому что почти все выбранные объявления в train были из нее. Еще учитывал локацию, так как чаще выбирали объявления из того же места

Сначала я использовал tf idf по словам и символьным нграммам, потом заменил словный поиск на bm25. Частоты слов считал через CountVectorizer из sklearn, дальше пересчитывал веса с k1 = 1.2 и b = 0.75. результаты объединил через rrf, локальным спискам дал двойной вес и добавил небольшой бонус за совпадение локации

Качество проверял на двух отдельных выборках по 2452 запроса из train. после замены словного tf idf на bm25 recall@50 вырос с 0.6629 и 0.6578 до 0.6802 и 0.6724

При проверке заметил, что глобальный поиск пропускает часть местных объявлений, поэтому добавил отдельный поиск внутри локации. Еще увеличил длину описания и параметров, это тоже улучшило результат

Для запуска нужны зависимости из requirements.txt. папка NLP_avito_interns с benchmark_items.parquet и benchmark_queries.parquet должна лежать рядом с папкой репозитория. main.py сохраняет answer.csv в папке репозитория, внешние api не используются
